# 커피 추출 계산기

GitHub Pages용 정적 웹앱입니다.

- `index.html` : 계산기 선택
- `machine.html` : 에스프레소/리스트레또/룽고 계산기
- `brewing.html` : 브루잉 계산기 및 Brewing Control Chart
- `styles.css` : 공통 디자인
- `machine.js`, `brewing.js` : 계산 로직
- `assets/brewing-control-chart.jpg` : 사용자가 제공한 차트 이미지

GitHub Pages에서 `main` 브랜치의 root를 배포 대상으로 선택하면 됩니다.
